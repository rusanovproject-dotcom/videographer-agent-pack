# Паттерны монтажа — что считать «мясом»

## Сигналы интересного момента

### Речевые сигналы (из транскрипта Deepgram)
Высокий приоритет:
- Восклицания, эмоции: «вау», «смотри», «офигеть», «работает!», «вот это да»
- Объяснение результата: «и вот результат», «получилось», «готово»
- Инсайт: «я понял», «ключевой момент», «важно», «фишка в том что»
- Демонстрация: «сейчас покажу», «смотрите что будет», «а теперь»
- Проблема и решение: «ошибка», «баг», «починил», «разобрался»

Низкий приоритет (вырезать):
- Заполнители: «эээ», «ммм», длинные паузы
- Повторы: одна мысль дважды
- Рутина: «подождём пока установится», «сейчас загрузится»

### Визуальные сигналы (из PySceneDetect + кейфреймов)
- Смена экрана/окна → новый этап
- Появление нового UI → демонстрация результата
- Терминал с быстрым выводом → процесс работает
- Веб-страница открылась → показ результата
- Курсор активно двигается → активная работа

### Аудио-сигналы (из FFmpeg)
- Речь после длинной паузы → начало нового блока
- Повышение громкости → эмоциональный момент
- Смех → позитивный момент

## Паттерны монтажа видеоуроков

### Структура финального видео
1. **Hook** (0:00-0:15) — самый яркий момент из урока (flash-forward)
2. **Intro** (0:15-0:30) — что будем делать, зачем
3. **Тело** — последовательность мясных моментов с переходами
4. **Результат** — финальная демонстрация что получилось
5. **Outro** (последние 10с) — call to action

### Правила нарезки
- Минимальная длина сегмента: 3 секунды
- Максимальная пауза между словами: 1.5 секунды
- Margin до/после речи: 0.3 секунды
- Переход между сценами: crossfade 0.5с или hard cut
- Субтитры: обязательно для всей речи

## Правила динамики (обновлено 2026-05-28, порог ужесточён)

**Плотность визуальных событий: ≥1 каждые ≤18 сек** (было 20 сек — снижен для validate-montage.py)

Визуальное событие = любое из: KineticText | Ken Burns / punch-in | overlay (MapEurope, Callout, QuoteCard) | ChapterWipe | LowerThird | flash/light-leak | xfade-переход.
Сквозные (ProgressStepper, CountUpTimer в углу) — НЕ считаются визуальными событиями.

**Самопроверка:** если нашёл сегмент >18 сек без события — добавить KineticText, Ken Burns или xfade.

**KineticText — дефолтный инструмент подчёркивания:**
Каждый смысловой блок видео должен иметь ≥1 KineticText на ключевое слово.
Ключевые слова для KineticText: числа+единицы, топонимы, названия инструментов, сильные утверждения.

**KineticText расширенный (2026-05-28):**
Подчёркивать НЕ только произнесённые слова — также выносить на экран факты/числа/шаги
которые НЕ озвучены в речи, но ценны для зрителя:
- цены («449 ₽/мес»), номера версий, числовые параметры
- названия шагов из плана («Шаг 3. DNS»), ключевые технические термины
- временны́е метки («~7 минут»), географические названия из UI

Добавляются как информационные плашки (KineticText или LowerThird) в «тихие» паузы.
Цель плотности ≤18 сек — это жёсткий критерий, не ориентировочный.

**Арсенал эффектов без mcp-video (2026-05-28):**
Все переходы, цветокор, динамика делаются через ffmpeg напрямую.
- xfade — на стыках всех сегментов (не hard-cut по умолчанию)
- Terminal Noir colorgrade — на весь ролик после overlay
- zoompan — на каждом смысловом блоке говорящей головы
- glitch/rgbashift — на хуке/моменте ошибки (≤3 сек, изолировано)
- flash — на ключевых демо-моментах (2-3 кадра через overlay)
Подробные команды: `knowledge/ffmpeg-recipes.md` ПРАВИЛО 12.

**Ken Burns / punch-in — дефолт на говорящей голове:**
Каждый блок где говорящая голова видна ≥10 сек → добавить плавный push-in zoompan.
Статичный кадр без движения 20+ сек = провал темпа.

### Правила удаления
- Тишина >2с → удалить (оставить 0.3с margin)
- «Ээээ» и «мммм» >1с → удалить
- Ожидание загрузки >5с → вырезать, вставить jump cut
- Повторные попытки → оставить только успешную
- Набор текста без комментариев >10с → ускорить x4

## Scoring: насколько момент «мясной» (1-10)

| Сигнал | Score |
|--------|-------|
| Демонстрация результата | 10 |
| Инсайт/открытие | 9 |
| Решение проблемы | 8 |
| Эмоциональная реакция | 8 |
| Объяснение ключевой концепции | 7 |
| Переход к новому этапу | 6 |
| Обычная работа с комментариями | 4 |
| Работа без комментариев | 2 |
| Ожидание/загрузка | 1 |
| Тишина | 0 |

Порог для включения в highlight reel: score >= 6

## Virality Scoring (для Shorts / Reels / TikTok)

> Добавлено 2026-05-27 — P1 апгрейд Videographer v2.

Для вертикального контента используется расширенный scoring по 8 типам сигналов.
Порог для Shorts жёстче: **score >= 8** (в отличие от highlight reel >= 6).
Хук обязателен в первые 3 секунды финального клипа.

| Тип сигнала | Score | Описание |
|-------------|-------|----------|
| Hook moment | 10 | «Я сделал X за Y время», провокационное утверждение в первые 3 сек |
| Opinion bomb | 10 | Резкое мнение против общепринятого: «все делают X, а надо Y» |
| Revelation | 9 | «Я узнал кое-что что изменило...», открытие/инсайт |
| Emotional peak | 9 | Видимая реакция: удивление, радость, восхищение |
| Conflict/tension | 8 | Проблема, неожиданная развилка, «всё пошло не так» |
| Story peak | 8 | Поворотный момент в нарративе |
| Quotable | 7 | Одна фраза которую хочется вырвать и поставить в сториз |
| Practical value | 7 | «Вот конкретный шаг который ты можешь сделать прямо сейчас» |

### Правила применения

- Порог для Shorts/Reels: score >= 8 (хук — минимум score 8, желательно 10)
- Хук обязателен в первые 3 секунды финального клипа
- Если хук не найден в первых 30% footage — сообщить владельцу перед рендером
- Для длинных видео (highlight reel, YouTube) — используй оригинальную таблицу scoring выше (порог >= 6)
