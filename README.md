# Видеограф — Режиссёр постпродакшена (agent pack)

**Что это.** Готовый к установке агент-видеограф для AI-офиса на Claude Code. Не редактор — думает как
зритель, режет как хирург. Берёт сырое видео и доводит до публикации:

1. **Анализирует footage** — транскрипция, детекция сцен и тишины, карта «мясных» моментов со score 1-10.
2. **Строит EDL-план монтажа** — что резать, что ускорять, где хук. План показывает тебе ДО нарезки.
3. **Нарезает** — убирает паузы, тишину, «ээ/мм», ускоряет скучное (через `mcp-video` или ffmpeg-фолбэк).
4. **Собирает** — склейка, цветокор, графика (Remotion: kinetic-текст, плашки, title cards), субтитры.
5. **Готовит под платформы** — YouTube 16:9, Shorts/Reels/TikTok 9:16, квадрат 1:1.
6. **Делает shorts** — вертикаль 9:16 с хуком в первые 3 сек и virality-scoring + Hormozi-капшены.

**Полный pipeline под ключ:** урок / highlight / shorts.

---

## ⚡ Быстрый старт (одна команда)

```bash
./install.sh ~/workspace      # путь к корню твоего AI-офиса (по умолчанию ~/workspace)
```

`install.sh` разложит файлы по местам, выставит права на скрипты, проверит зависимости
(`ffmpeg`, `uvx`, `npm`, `DEEPGRAM_API_KEY`) и подскажет 2 ручных шага. Повторный запуск безопасен —
твою память/правила (`memory.md`, `failures.md`, `overrides.md`) не затирает.

После установки — открой Claude Code и скажи: **«Видеограф, представься»** — он проведёт онбординг
и предложит подключить инструменты ПО ОЧЕРЕДИ. Или сразу: **«Видеограф, обработай урок <путь к видео>»**.

## Что внутри пака

```
videographer/
├── README.md                   # этот файл
├── install.sh                  # установка в один заход (идемпотентная)
├── videographer.md             # субагент-обёртка → положить в .claude/agents/
└── agent/                      # тело агента → положить в office/agents/videographer/
    ├── CLAUDE.md soul.md       # ядро + душа монтажа (стиль, дефолты)
    ├── memory.md failures.md   # ПУСТЫЕ шаблоны (наполнит сам в твоём офисе)
    ├── overrides.md            # твои правила поверх ядра (стиль, бренд, платформы)
    ├── ONBOARDING.md           # сценарий первого запуска + MCP по очереди
    ├── architecture.mermaid    # схема пайплайна
    ├── knowledge/              # toolchain, EDL-схема, форматы платформ, ffmpeg-рецепты, паттерны
    ├── skills/                 # video-analyze / edl / cut / assemble / lesson / shorts / graphics
    └── remotion-studio/        # Remotion-студия графики (src + scripts, БЕЗ node_modules/рендеров)
```

> **Пак чист по ПД.** Память, фейлы, история стиля — пустые шаблоны. Ключи берутся из переменных
> окружения (`DEEPGRAM_API_KEY`), никаких захардкоженных путей или токенов. `remotion-studio` без
> `node_modules` и рендеров — ставится `npm install` на месте.

Перед публикацией обновлённого пака или своего форка запусти проверку:

```bash
bash scripts/pack-check.sh .
```

Она проверит комплектность скиллов, внутренние ссылки, frontmatter, приватные пути и признаки секретов.

## Зависимости

| Нужно | Зачем | Проверка | Без него |
|-------|-------|----------|----------|
| `ffmpeg` + `ffprobe` | ядро всех видеоопераций | `ffmpeg -version` | **не работает вообще** — поставь первым |
| `uvx` (uv) | запуск `mcp-video` | `uvx --version` | mcp-video недоступен → ffmpeg-фолбэк |
| `npm` (Node.js) | Remotion-графика | `npm -v` | графика недоступна, нарезка/субтитры работают |
| `DEEPGRAM_API_KEY` | транскрипция (Deepgram) | `echo $DEEPGRAM_API_KEY` | fallback на локальный Whisper |

Графика (один раз): `cd office/agents/videographer/remotion-studio && npm install`.

## MCP-инструменты (подключаются при онбординге, по очереди)

Видеограф сам предложит их по одному с объяснением пользы. Кратко:

| MCP | Зачем | Команда | Без него |
|-----|-------|---------|----------|
| **mcp-video** (рекоменд.) | ~119 инструментов монтажа (trim/silence/speed/crop/subtitles) | `claude mcp add mcp-video -- uvx --from mcp-video mcp-video` | прямой ffmpeg (полный арсенал, не деградация) |
| ElevenLabs (опц.) | TTS + многоязычные субтитры | `claude mcp add elevenlabs -- uvx elevenlabs-mcp` | субтитры через Remotion/mov_text |
| Pexels (опц.) | сток b-roll | `claude mcp add pexels -- uvx pexels-mcp-server` | только своё footage + Remotion |

Полный список и нюансы — `agent/knowledge/toolchain.md`. Сценарий онбординга — `agent/ONBOARDING.md`.

## Установка вручную (если не через `install.sh`)

Офис на Claude Code со структурой `office/agents/` + `.claude/agents/`.

```bash
# из корня этого пака
cp -R agent/        <workspace>/office/agents/videographer/
cp    videographer.md <workspace>/.claude/agents/videographer.md
chmod +x <workspace>/office/agents/videographer/remotion-studio/scripts/*.mjs \
         <workspace>/office/agents/videographer/remotion-studio/render.mjs
# графика (опционально):
cd <workspace>/office/agents/videographer/remotion-studio && npm install
```

### Регистрация в своём офисе

**В `office/AGENTS.md`** — строка в таблицу команды:

```markdown
| **Видеограф** | Режиссёр постпродакшена: анализ footage → EDL → нарезка → сборка → субтитры → форматы → shorts | «видеограф», «видео», «монтаж», «нарезка», «shorts», «смонтируй», «обработай урок» | `office/agents/videographer/` |
```

**В `office/CLAUDE.md`** (мозг оркестратора) — строка роутинга:

```markdown
| видео, монтаж, нарезка, shorts, reels, субтитры к видео, EDL, смонтируй, обработай урок, сделай шортс | **Видеограф** → анализ→EDL→нарезка→сборка→субтитры→форматы. Сначала показывает EDL-план, рендерит после «ок». | Контент и каналы |
```

> Имя «Видеограф» узнаётся по протоколу адресации агентов: «Видеограф, …» → загрузка обёртки через Agent tool.
> Если такого протокола нет — агент всё равно вызывается напрямую через Agent tool по файлу `.claude/agents/videographer.md`.

## Принципы (почему Видеограф так устроен)

- **Сначала план, потом рендер.** Всегда показывает EDL (что резать) и ждёт «ок» — не рендерит вслепую.
- **Монтаж = найти историю.** Режет без сожаления то, что не добавляет. Финал ≤ 80% исходника.
- **Хук в первые 3 сек** — или короткий клип мёртв.
- **Плотность.** Визуальное событие каждые ≤18 сек, движение на каждом смысловом блоке.
- **Graceful degradation.** Нет mcp-video → ffmpeg. Нет Deepgram → Whisper. Нет npm → без графики, но монтаж идёт.
- **Портабельность.** Ключи — из окружения, пути — относительные. Пак работает у каждого без правок.

## Настройка под себя

- **`agent/overrides.md`** — твои правила поверх ядра: стиль монтажа, бренд-китинг, платформы по умолчанию,
  что не трогать. Не перезаписывается при апдейте ядра.
- **`agent/soul.md`** → блок «Мои настройки» (tempo / subtitle_style / hook_style / platforms / пороги score).
- **`agent/knowledge/formats.md`** — параметры платформ, если нужны свои пресеты.
